概述

GAuth 是一个浏览器扩展，用于生成两步验证码。GAuth 没有自己的服务器，不收集、不出售、不向任何第三方分享你的数据，也不包含广告或统计分析代码。

保存在你设备上的数据

  • 你添加的账号（发行方、账号名、两步验证密钥）、分组和设置，以加密形式保存在浏览器的扩展存储中。
  • 如果你设置了解锁口令，密钥只在解锁期间保留在内存里。
  • 这些数据只在你的设备上，卸载扩展即被删除。

Google 账号与云端硬盘（可选）

只有你主动点「连接 Google 账号」时，GAuth 才会请求唯一一项权限：

  • https://www.googleapis.com/auth/drive.file：只能访问 GAuth 自己创建的文件，即你云端硬盘中的「GAuth 备份」文件夹及其中的备份文件。GAuth 看不到你云端硬盘里的其他文件。

连接后，GAuth 会通过云端硬盘接口读取该账号的邮箱地址，仅用于在扩展界面里显示当前连接的是哪个账号。

备份在上传前，已用你自己设置的备份口令在本机加密（PBKDF2-SHA256 + AES-GCM）。云端硬盘里只有密文，GAuth 的开发者和 Google 都无法解开。访问令牌只保存在浏览器会话内存中，不会发送到 Google 以外的任何地方。

你可以随时在扩展里「断开 Google」，或在 Google 账号权限页面 撤销 GAuth 的访问权限；云端的备份文件由你自行保留或删除。

GAuth 对通过 Google API 获得的信息的使用和传输，遵守 Google API 服务用户数据政策，包括其中的「有限使用」要求。

网页自动填充

为了在网页的验证码输入框里填入验证码，GAuth 会在你访问的网页上检测验证码输入框。它只把验证码交给网页，不会把密钥交给网页，也不会读取、记录或上传网页内容。填入后按回车提交是可以在设置里关闭的本机操作，不会产生任何额外的数据传输。

摄像头与屏幕截图

只有你选择「用摄像头扫码」或「扫描当前网页的二维码」时，GAuth 才会使用摄像头画面或当前标签页截图来识别二维码。识别在本机完成，图像不会保存或上传。

屏幕锁

GAuth 会在电脑锁屏或长时间无操作时自动锁定自己。它只读取系统给出的「活动 / 空闲 / 已锁屏」状态，不记录也不上传这些信息。

政策变更与联系方式

如本政策有变更，会更新此页面并修改生效日期。如有疑问，请在 GitHub Issues 提交。

Privacy Policy

Effective date: November 1, 2026

Overview

GAuth is a browser extension that generates two-factor authentication codes. GAuth has no servers of its own. It does not collect, sell or share your data with any third party, and it contains no advertising or analytics code.

Data stored on your device

  • Accounts you add (issuer, account name, 2FA secret), groups and settings are stored encrypted in the browser's extension storage.
  • If you set an unlock passcode, secrets are kept in memory only while GAuth is unlocked.
  • This data stays on your device and is removed when you uninstall the extension.

Google account and Google Drive (optional)

Only when you choose “Connect Google account” does GAuth request a single scope:

  • https://www.googleapis.com/auth/drive.file: access only to files created by GAuth, namely the “GAuth 备份” folder in your Drive and the backup files in it. GAuth cannot see any other files in your Drive.

After connecting, GAuth reads the account's email address through the Drive API, used only to show in the extension which account is connected.

Backups are encrypted on your device with a passphrase you choose (PBKDF2-SHA256 and AES-GCM) before upload. Only ciphertext is stored in your Drive; neither the GAuth developers nor Google can decrypt it. Access tokens are kept in browser session memory and are never sent anywhere other than Google.

You can disconnect at any time in GAuth, or revoke access on your Google Account permissions page. Backup files in your Drive are yours to keep or delete.

GAuth's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Autofill on web pages

To fill codes into verification fields, GAuth detects such fields on the pages you visit. It passes only the one-time code to the page, never the secret, and it does not read, record or upload page content. Pressing Enter after filling is a local action that can be turned off in Settings and involves no additional data transfer.

Camera and screenshots

The camera, or a screenshot of the current tab, is used only when you choose “Scan with camera” or “Scan QR code on this page”. Recognition happens on your device; images are neither stored nor uploaded.

Screen lock

GAuth locks itself when your computer locks or after a period of inactivity. It reads only the system's active / idle / locked state and neither records nor uploads it.

Changes and contact

Changes to this policy will be posted on this page with a new effective date. For questions, please open an issue on GitHub Issues.

Politique de confidentialité

Date d’entrée en vigueur : 1er novembre 2026

Présentation

GAuth est une extension de navigateur qui génère des codes d’authentification à deux facteurs. GAuth n’a aucun serveur. Elle ne collecte pas vos données, ne les vend pas et ne les partage avec aucun tiers. Elle ne contient ni publicité ni code de mesure d’audience.

Données stockées sur votre appareil

  • Les comptes que vous ajoutez (émetteur, nom du compte, clé secrète 2FA), les groupes et les réglages sont stockés chiffrés dans l’espace de stockage de l’extension.
  • Si vous définissez un code de déverrouillage, les clés secrètes ne restent en mémoire que tant que GAuth est déverrouillée.
  • Ces données restent sur votre appareil et sont supprimées lorsque vous désinstallez l’extension.

Compte Google et Google Drive (facultatif)

Uniquement lorsque vous choisissez « Connecter un compte Google », GAuth demande une seule autorisation :

  • https://www.googleapis.com/auth/drive.file : accès aux seuls fichiers créés par GAuth, c’est-à-dire le dossier « GAuth 备份 » de votre Drive et les fichiers de sauvegarde qu’il contient. GAuth ne voit aucun autre fichier de votre Drive.

Une fois connectée, GAuth lit l’adresse e-mail du compte via l’API Drive, uniquement pour afficher dans l’extension le compte connecté.

Les sauvegardes sont chiffrées sur votre appareil avec une phrase secrète que vous choisissez (PBKDF2-SHA256 et AES-GCM) avant l’envoi. Seul le texte chiffré est stocké dans votre Drive ; ni les développeurs de GAuth ni Google ne peuvent le déchiffrer. Les jetons d’accès restent dans la mémoire de session du navigateur et ne sont jamais envoyés ailleurs que chez Google.

Vous pouvez vous déconnecter à tout moment dans GAuth, ou révoquer l’accès depuis la page des autorisations de votre compte Google. Les fichiers de sauvegarde de votre Drive vous appartiennent : vous les conservez ou les supprimez.

L’utilisation et le transfert par GAuth des informations reçues des API Google respectent les règles sur les données utilisateur des services d’API Google, y compris les exigences d’utilisation limitée.

Remplissage automatique sur les pages web

Pour remplir les champs de code de vérification, GAuth détecte ces champs sur les pages que vous visitez. Elle ne transmet à la page que le code à usage unique, jamais la clé secrète, et ne lit, n’enregistre ni n’envoie le contenu des pages. L’appui sur Entrée après le remplissage est une action locale, désactivable dans les réglages, qui n’entraîne aucun transfert de données.

Caméra et captures d’écran

La caméra, ou une capture de l’onglet actif, n’est utilisée que lorsque vous choisissez « Scanner avec la caméra » ou « Scanner le code QR de la page ». La reconnaissance se fait sur votre appareil ; les images ne sont ni conservées ni envoyées.

Verrouillage

GAuth se verrouille lorsque votre ordinateur se verrouille ou après une période d’inactivité. Elle ne lit que l’état actif / inactif / verrouillé fourni par le système, sans l’enregistrer ni l’envoyer.

Modifications et contact

Toute modification de cette politique sera publiée sur cette page avec une nouvelle date d’entrée en vigueur. Pour toute question, ouvrez un ticket sur GitHub Issues.
